New simulation

Builds an environment.yaml, runs the fidelity lint, and installs it. A fleet that fails the lint is never installed. The name fixes the seed and every node GUID, so it cannot change later without orphaning the fleet's history.

Claim

One claim covers the whole fleet — every simulated node appears in the Space automatically. The token is sent straight to the agent and is never stored, logged, or written to any file.

Teardown

Disarms scenarios, stops the plugin process (removing the file is not enough), and archives the environment, seed and scenario manifests — the artifacts that replay the identical world. Cloud-side steps stay manual and say so.
